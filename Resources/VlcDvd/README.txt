These files are plugins of VLC 3.0.24 (the same version as the LibVLC package of this program), copied unchanged from a VLC installation (https://www.videolan.org/vlc/):
  access\libdvdnav_plugin.dll, access\libdvdread_plugin.dll: video DVDs with menus (the LibVLC package has no DVD reader).
  packetizer\libpacketizer_a52_plugin.dll: puts the frames of Dolby Digital (AC-3) audio in order. Without it the sound of a DVD is damaged (found 2026-11-17).
They are GPL-licensed (COPYING.txt in this folder).
Source code: https://code.videolan.org/videolan/vlc (tag 3.0.24); see also libdvdread/libdvdnav at https://code.videolan.org/videolan/
When LibVLC is updated, copy the plugins of the same VLC version here.
